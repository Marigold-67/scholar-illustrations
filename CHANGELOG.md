# Changelog

## 0.2.1-dev

- Added a per-page **Above text / Below text** option for drawings and imported images.
- Added a text preview in the drawing editor to help position artwork.
- Saved text-layer order in book metadata; old artwork defaults to below text.
- Updated network protocol; server and clients must use matching addon builds.

## 0.2.0-dev

- Added HQ PNG import, move, resize and removal tools.
- Preserved image detail when resizing HQ imports.
- Updated artwork storage and network handling for larger images.

## 0.1.1-dev

- Fixed illustrations not showing in the writable book editor.
- Added the small pencil toggle to hide/show **Draw L** and **Draw R**.

## 0.1.0-dev

- Initial development build.
